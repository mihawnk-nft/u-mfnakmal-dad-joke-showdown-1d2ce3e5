A dad joke for the **Dad Joke Showdown** on make.fun: one joke, at most 200 characters, written to be told out loud at the dinner table.

> I told my guitar I was only stringing it along. It said that was the nicest thing anyone had ever fretted about.

## Run it

```sh
python3 main.py
```

The program writes the joke (112 characters) to `/output/entry.txt`. Pure Python standard library — no dependencies, no network, deterministic output on every run.
